# Personal Portfolio

A personal portfolio website built with React, TypeScript and Vite, showcasing my projects, technical skills and experience in software development.

I'm currently studying Informatics with a specialization in Systems Development at Mid Sweden University. Through this portfolio, I present selected projects and highlight my approach to development, design, problem-solving and continuous improvement.

## Featured Projects

### Vehicle Monitoring

A web-based monitoring system developed through a university collaboration with a company.

The application monitors onboard devices installed in buses, providing insights into CPU temperature, RAM usage, boot counts and device reporting status.

Initially developed as a team project, the system was later independently extended with additional functionality, improved visualizations and further refinements.

**Technologies:** C#, ASP.NET Core MVC, MongoDB

### Stillia

An Android application focused on digital wellbeing and screen time awareness.

The project involved independently developing and refining the application, with a focus on user experience, interface design, navigation, screen time statistics and testing.

**Technologies:** Kotlin, Jetpack Compose, Android

## Getting Started

Clone the repository:

```bash
git clone https://github.com/EmmaSjoberg/Portfolio.git
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```
